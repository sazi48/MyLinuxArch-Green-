# 🟢 My Hyprland Dotfiles

Personal configuration for Arch Linux with the Hyprland window manager. 
The theme is designed in dark green tones.

---

# 🟢 Мои конфиги Hyprland

Персональная конфигурация Arch Linux с оконным менеджером Hyprland. 
Тема оформления выдержана в темно-зеленых тонах.


![Screenshot](assets/desktop.png)


## 🛠️ Components / Компоненты

*   **OS:** Arch Linux
*   **WM:** [Hyprland](https://hyprland.org/)
*   **Bar:** [Waybar](https://github.com/Alexays/Waybar)
*   **Terminal:** [Kitty](https://sw.kovidgoyal.net/kitty/)
*   **Launcher:** [Wofi](https://hg.sr.ht/~scoopta/wofi)
*   **Notifications:** [Dunst](https://dunst-project.org/)
*   **Themes:** Candy-Icons, Everforest (GTK)

## 🚀 Installation / Установка

### English
1. Clone the repository:
   ```bash
   git clone https://github.com/sazi48/my-hyprland.git
   cd my-hyprland
   ```

2. Run the automated installer:
   ```bash
   ./install.sh
   ```

3. The script will automatically install all packages (including AUR), copy the configurations, and prompt you to reboot.

### Русский

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/sazi48/my-hyprland.git
   cd my-hyprland
   ```

2. Запустите автоматический установщик:
   ```bash
   ./install.sh
   ```

3. Скрипт сам установит все пакеты (включая AUR), скопирует конфиги и предложит перезагрузить компьютер.


## ⌨️ Keybindings / Горячие клавиши


| Keybinding (Комбинация) | Action (Действие) |
| :--- | :--- |
| SUPER + Q | Open terminal / Открыть терминал |
| SUPER + R | App launcher / Меню приложений |
| SUPER + B | Open browser / Открыть браузер |
| SUPER + O | Open Obsidian / Открыть Obsidian |
| ALT + TAB | Switch workspaces / Переключение столов |
| SUPER + S | Scratchpad / Скрытый стол |
